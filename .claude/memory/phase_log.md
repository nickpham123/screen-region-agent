- 2026-08-21 (later): Root mechanism for the whole hold/release failure class finally identified — **`globalShortcut` consumes the trigger key's original keydown, leaving the overlay blind to the key until macOS auto-repeat starts (~445ms measured)**, and a key the window never saw produces no keyup either. This single fact explains the "intermittent quick-tap" bug (deterministic: release under ~445ms), the "hotkey sometimes does nothing" reports (the accelerator is unregistered for the duration of a hung gesture), and the lingering trail after a tap. Mitigated with a 2.5s initial-liveness deadline, sized above macOS's slowest configurable repeat delay so it can't truncate genuine holds. Also fixed: the phantom activation trail — caused by mixing the main process's activation point with the renderer's `clientX/clientY` (they disagree by a few px for the same stationary cursor), not by the suspected residual point, which was measured and disproven. `decisions.md` now carries one consolidated narrative entry for hold/release detection instead of scattered correction rows. Still open: focus instability on activation, now the largest remaining source of failed gestures.
- 2026-08-21: Step 3 closeout — **`Alt+Space` was silently broken and is replaced**. What began as removing a disproven 50ms settle buffer surfaced a total failure: 25 consecutive gestures lost the trigger key's `keyup`, including deliberate holds that the previous session recorded as verified. Isolating one variable at a time ruled out the buffer (the failure reproduced identically in the pre-edit configuration), then the Step 1 placeholder window stealing focus, and landed on the accelerator: macOS routes `Option+<key>` through the text-input/composition layer (Option+Space = U+00A0), which swallows the trigger key's events. `Control+Shift+D` → 8/11 finalized; `Control+Shift+Space` (isolating Option from Space) → 8/11 with zero missing keyups, proving Option was the culprit and Space was always fine. `uiohook-napi`'s revisit trigger appeared to fire and then didn't — the mechanism was never at fault. Also fixed in closeout: the stuck-gesture safety net was force-closing genuine in-progress holds at 5s (4 occurrences), now reworked into a liveness watchdog driven by auto-repeat keydowns. Current accelerator is verified-working but ergonomically poor and explicitly interim.
